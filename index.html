04 — Panel Discussion

四方實戰對談

這場不是技術論壇，而是讓觀眾開始產生合作慾望。

「AI 如何真正落地商業？——從流量、會員到決策，AI Agent 如何重構企業成長模式」
Sam 商業策略 / 整體觀點
David AI 基礎建設 / 技術可信度
Vinek CRM / 顧客經營
Mars 流量 / 廣告 / 成長
Q01 — 開場破題
「現在大家都在講 AI，但你認為，企業真正缺的到底是『AI 工具』，還是『AI 思維』？」
→ Sam 主答 · David 補充
Q02 — 技術落地
「很多企業都想導入 AI Agent，但真正卡住的是什麼？技術、資料，還是組織？」
→ David 主答 · Mars / Vinek 各補充
Q03 — 流量焦慮
「現在廣告越來越貴、流量越來越難買，AI Agent 真的能改善投放成效嗎？」
→ Mars 主答
Q04 — 轉換與 CRM
「很多企業流量不少，但真正能留下來的顧客很少——AI Agent 在 CRM 裡最有價值的是什麼？」
→ Vinek 主答
Q07 — 高潮爆點
「你覺得未來 3 年，最容易被 AI 淘汰的是什麼樣的行銷團隊？」
→ Sam · 這題會爆 🔥
